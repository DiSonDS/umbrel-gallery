# DiSonDS Umbrel App Gallery

Gallery assets for apps in the [DiSonDS Umbrel App Store](https://github.com/DiSonDS/umbrel).

Each app folder contains:

- `icon.svg` — App Store icon (256×256 preferred, no rounded corners)
- `1.png`, `2.png`, `3.png`, … — gallery screenshots

Reference raw GitHub URLs from each app's `umbrel-app.yml`.
